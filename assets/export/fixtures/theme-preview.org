* A system for structured plain text

Org Mode is an authoring tool and TODO list manager built around a lightweight,
human-readable plain-text format. 它是一套结构化纯文本系统，可用于写作、笔记、
任务管理、项目规划与发布。

Inline code such as =[4/7]= stays readable, *bold text* carries the accent, and
/emphasis/ marks the quieter voice. See [[https://orgmode.org][orgmode.org]] for
the full manual.

** One file, many workflows

- Foldable outlines and structured writing
- TODO items, schedules, and Agenda views
  - Nested detail stays aligned
  - Publishing and literate programming
- 中文列表项与英文条目共用同一套版式

1. Parse the document incrementally
2. Render only what is on screen
3. Write results back to the file
